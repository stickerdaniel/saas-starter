# Internationalization

The app ships in four languages: English, German, Spanish, and French. The language is part of the URL (`/de/pricing`, `/fr/privacy`), so every localized page can be shared and indexed on its own, and search engines get `hreflang` alternates for each one (see [Agents and SEO](agents-and-seo.md)). A language switcher lets visitors change it.

Translations live in committed JSON files, one per language, and the app builds from them without any external service. [Tolgee](https://docs.tolgee.io/) is optional: with an API key, it adds in-context editing during development and a deploy-time translation sync.

Accessible labels are translated too. A lint rule rejects a hardcoded `aria-label` or screen-reader-only text, so a new control cannot ship with English-only accessibility copy.

## Where to start in the code

- [`src/i18n/`](../../src/i18n/): the translation files, with English as the source language
- [`src/lib/i18n/languages.ts`](../../src/lib/i18n/languages.ts): the language registry; run `bun run i18n:sync` after adding or removing a language
- [i18n setup guide](../setup/i18n/i18n-setup.md): Tolgee options and the self-hosted alternative
- [`eslint/rules/no-hardcoded-aria-label.js`](../../eslint/rules/no-hardcoded-aria-label.js) and [`no-hardcoded-sr-only.js`](../../eslint/rules/no-hardcoded-sr-only.js)
